Everything belongs to a trip

Rides, meals, hotel rooms, cosplays and photos all belong to one event, but the app spreads them across tabs that show every event mixed together. This page lists every page the app has today, shows where it goes wrong, and proposes a structure built around the trip, with five tabs and one menu for everything personal.

What the index shows

Why it feels disorganised

  • Three tabs mix every event

    Transport, Eten and Financiën list everything from every event. Only the Hub knows which trip is next. Right before HDCC, the Transport list still shows last month's rides and the Halloween party's rides, all in one list.

  • Trip pages are hidden two levels deep

    Hotelkamers and Cosplays can only be opened from an event page. Photos of a past trip are in "Meer › Story archief". Acties can only be reached from a banner that disappears when there's nothing left to do.

  • "Meer" holds everything that didn't fit elsewhere

    The only full calendar (the most important list in the app) sits next to a QR code, the YouTube link and the greeting toggle, under a page subtitle that says "Instellingen".

  • Things lead nowhere, or exist twice

    Missing-ride actions don't link to Transport. Hotel room rows on the Hub have an arrow but do nothing. "Kamer 214" comes from a user field that can disagree with the actual room assignments.

Proposal

Five tabs, one personal menu

Each tab answers one question. The Event tab is new: it's the trip's own space, and pages that are hard to find today become its sub-tabs. The grey text under each item shows where it lives now. The Event tab reopens the sub-tab you used last.

Hub

What's next for me?

  • Next tripwas: event carousel
  • Voor jouwas: Acties banner + /acties
  • Snel: rit, locatie, fotowas: Hub tiles, only shown during a trip

Event

Everything for one trip

  • Overzichtwas: event page (per day)
  • Vervoerwas: Transport tab
  • Etenwas: Eten tab
  • Kamerswas: event page › Hotelkamers
  • Cosplaywas: event page › Cosplays
  • Foto'swas: Story archief + Hub rings

Agenda

Which events are there?

  • Lijst & maandwas: Meer › Con Kalender
  • Aanmeldenwas: 3 separate places
  • Geweestwas: Geschiedenis; each past trip shows its photo rings
  • Abonneren (.ics)was: small button in Meer

Financiën

Who owes whom?

  • Saldounchanged
  • Te betalen / bevestigenwas: Acties
  • Uitgaven per tripnew: uses the existing linked_event_id field

Crew

Who's who, and where?

  • Ledenwas: Meer › Leden + Hub list
  • Waar is iedereenwas: Hub › Locatie pingen
  • Profielennew: others' profiles can be opened

Considered

Why not keep the Transport and Eten tabs?

Recommended

A · Event tab with sub-tabs

  • Transport, meals, rooms, cosplays and photos all appear for the same trip, in one place
  • Hidden pages become one tap from the tab bar
  • One event picker instead of one per tab
  • People need to learn that Transport is now inside Event
  • More route changes (with redirects)

B · Keep the tabs, add a trip filter to each

  • Smallest change; nobody has to look for Transport
  • Kamers, Cosplay and Foto's still have no place in the nav
  • Every tab needs its own trip filter, and they can get out of sync
  • "Meer" stays, because the calendar still has nowhere else to go
For the code

Routes

A trip is identified by multi_day_id for multi-day events, or by the event id for a single day. This is the same grouping the backend already uses for hotel rooms (_hotel_group_key). It is not event_group_id: HDCC editions stay separate trips and can become a filter in Agenda. All paths stay in English, and /acties (the only Dutch path) goes away.

Before the rework

Fixes that can ship now

These don't depend on the new structure.

  • Hub hotel room rows show an arrow but do nothing. Remove the arrow or link the rows to the rooms page.pages/HubPage.tsx
  • Acties missing-ride cards don't link anywhere. Link them to Transport or the event.pages/acties/components/ActionCard.tsx
  • Other people's profiles can't be opened. Add "Bekijk profiel" to the popup, and fix your own "Bekijk profiel" button, which links to the page you're already on.components/common/UserProfilePopup.tsx · pages/ProfilePage.tsx
  • Duplicate settings: remove Notificaties and Uitloggen from Meer, and keep Begroeting and Discord in one place.pages/MorePage.tsx · pages/ProfilePage.tsx
  • Ride title shows "Inbound/Outbound". Use Heen/Terug.pages/RideDetailPage.tsx
  • One source for hotel rooms: "Kamer X" should come from room assignments, not the free-text user.hotel_room.CrewSection · MembersPage · UserProfilePopup · AdminUsersPage
  • /test-error is public. Move it behind the admin route.router.tsx
  • Unused code: CosplayDetailPage (no route), EventAttendees, CrewList, 6 unused Hub components and 2 unused finance components.components/hub · components/finance · components/more
  • Tab icons are matched to tabs by position in the array, so reordering the tabs breaks them. Store each icon on its nav item.components/layout/BottomNav.tsx · constants/index.ts
