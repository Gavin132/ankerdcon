Ankerd Con · UI proposal · desktop rework · Sep 2026

A desktop app that looks like Ankerd

On a phone the app works well. On a laptop it's that same phone layout sitting in the middle of the screen, in the soft slate-and-sky style every AI chat app uses. This proposal adds a real desktop layout, keeps the phone structure people already know, and gives both a look based on our own mascot.

What Gavin is seeing

Why it looks off on desktop

  • It's the phone layout, just centered

    AppShell limits every page to 672 px and BottomNav stays pinned to the bottom. More than half of a laptop screen is empty, and the tab bar is far from where a mouse usually is.

  • It uses the same look as every AI app

    Slate greys, sky-blue gradients, frosted glass, Inter, soft blue shadows, and rounded-2xl on everything. That's the default Tailwind SaaS style, so it reads as "chat app", not "con crew".

  • The mascot isn't used anywhere

    The goofy cyan anchor with the thick black outline is the most recognisable thing we have. Right now it's a 24 px icon in the header.

Proposal

The new desktop layout

Click Hub, Transport and Financiën in the sidebar, or use the sun/moon button. At tablet width the sidebar shrinks to icons, and at phone width the tab bar comes back.

Mobile

The same style on phones

What changes

Five decisions

Bottom tab bar on every screen size

A sidebar from 1024 px up, the same tab bar below that

On desktop, navigation moves to a left sidebar that also has room for Kalender, Hotelkamers, Cosplays and Stories, which are hidden behind "Meer" today. It works like the admin portal already does. On tablets the sidebar shrinks to icons, and phones keep the tab bar, restyled with the ink pill for the active tab.

One 672 px column

Use the screen width: main content plus a side column

The Hub gets an 8/4 split: the trip on the left, and your actions and balance on the right. Transport becomes a board with Heen / Restaurant / Terug columns and a short list of who has no ride. Financiën becomes a real table. Each page puts the content that needs the space in the wide column.

Slate, sky gradients, glass, soft blue shadows

A look based on the mascot: ink outlines and anchor cyan

The mascot's thick black outline becomes the 2px outline for the few things that matter most: the next-trip ticket, primary buttons and the active nav item. Only primary buttons keep a small hard shadow so they read as pressable. Everything else stays flat with thin hairlines. Cyan is the single brand color, and red, amber and green are only used for status.

Inter for everything

Poster type for events, a mono font for times and money

Event names, countdowns and room numbers use a condensed display font, like a con wristband or badge. The UI text uses Poppins. Departure times, amounts and dates use a monospace font so they line up.

Every feature on the home screen

Fewer things per screen, and one bold element each

Each page leads with one outlined element (the ticket on the Hub, the "Rit toevoegen" button on Transport) and keeps the rest quiet: no avatar stacks on every row, no button on every card, and status colors only where something needs doing. Details stay one click away.

Depth

Depth: flat

We compared three levels of depth and chose flat. It fits the mascot drawing best and keeps the screens calm. The other two are kept here for reference.

Ik rijd

Flat Chosen

The key element per screen, like the Hub ticket, stands out with a thick ink outline and cyan, not a shadow. Only primary buttons keep a small hard shadow. Nothing moves on hover.

  • Calmest; looks like the mascot drawing
  • Primary buttons still press in when tapped
Ik rijd

3D

Cards and buttons get a solid bottom edge, like a keycap or an enamel pin. Buttons sink when you tap them, and cyan gets a slight shine like the mascot.

  • Feels tactile, which suits a phone-first app
  • Same visual language as the ink outline
  • No blur, so it's cheap to render on older phones
  • Every card gets an edge, and cards lift on hover, which looked odd
Hub · Event · Agenda

3D + liquid glass

Same as 3D, plus a translucent, blurred tab bar and sidebar that float over the content, like iOS 26.

  • Looks current, especially the floating tab bar
  • Glass only works with something colorful moving behind it; over calm screens it looks like a plain white panel
  • Blur is heavy on older Android phones, which matters for a PWA
  • Closest to the frosted glass the app already has (.glass in index.css), which is part of what looks generic

How we'd build it

Rollout order

Each step can ship on its own. Only the sidebar in step 2 is desktop-only. Every other step changes phones too, the way the mobile screens above show.

  1. Tokens and fonts

    Swap the palette and fonts app-wide first. This alone removes most of the "AI app" feel, on every screen size.

    tailwind.config.tssrc/index.cssindex.html (Poppins + Big Shoulders + Spline Sans Mono)

  2. Desktop shell

    Add a new sidebar, hide the tab bar from lg up, remove the 672 px limit and move search into the header.

    components/layout/Sidebar.tsx (new)components/layout/AppShell.tsxcomponents/layout/BottomNav.tsxcomponents/layout/Header.tsx

  3. Hub

    Make the 8/4 grid, turn the upcoming-event card into the ticket, and move actions and balance into the side column. Hotel rooms and quick rides get their own pages instead of sitting on the Hub.

    pages/HubPage.tsxcomponents/hub/UpcomingEventCard.tsxcomponents/hub/DailyActionCheck.tsx

  4. Transport and Financiën

    Turn Transport into a board grouped by direction on desktop, with Heen / Restaurant / Terug tabs on phones. Show expenses as a table on desktop and a list on phones. The main action goes in a floating cyan button on mobile.

    pages/TransportPage.tsxcomponents/transport/RideCard.tsxpages/FinancePage.tsx

  5. Detail pages and drawers

    Event, meal and ride pages get two columns with key info that stays visible while you scroll. On desktop, drawers open as side panels instead of bottom sheets.

    pages/EventDetailPage.tsxcomponents/common/Drawer.tsxcomponents/detail/DetailTopbar.tsx

All names, rides, rooms and amounts in the mock are sample data to show the layout.
